# Project Overview

A coding challenge documentation site built with [Rspress](https://rspress.dev/) (React-based static site generator). The site publishes algorithm problem explanations and solutions in Chinese, currently focused on array/hash topics.

## Commands

- `pnpm run dev` — start dev server
- `pnpm run build` — production build
- `pnpm run lint` — ESLint
- `pnpm run format` — Prettier

## Architecture

- **docs/** — Rspress content root. MDX files are the challenge write-ups organized by topic (e.g., `docs/coding-challenges/array-hash/`). Navigation is auto-generated by `rspress-plugin-auto-nav` from `_meta.json` files.
- **src/** — TypeScript algorithm implementations, one directory per problem (e.g., `src/can-complete-circuit/index.ts`). These are standalone solutions, not imported by the docs site.
- **theme/** — Minimal custom theme extending `@rspress/core/theme-original` with custom CSS.
- **rspress.config.ts** — Site config; base path is `/code-insights/`.

## Adding a New Challenge

1. Create `src/<problem-name>/index.ts` with the solution implementation.
2. Create `docs/coding-challenges/<topic>/<problem-name>.mdx` with the write-up (use `Badge` components for tags, include problem description, analysis, and code sections with `Tabs`/`Tab`).
3. Update the relevant `_meta.json` to register the new page in navigation. **Only push new nav items to the end of `_meta.json`.Do not insert them elsewhere.**

## Conventions

- Documentation and comments are written in Chinese.
- MDX files use Rspress components (`Badge`, `Tabs`, `Tab`) imported from `@rspress/core/theme`.
- TypeScript strict mode is enabled; `noUnusedLocals` and `noUnusedParameters` are enforced.
